Privacy Policy

Last updated: November 13, 2026

Clips Uploader ("the app") is a private tool used only by its owner to upload videos to the owner's own YouTube channel. It is not offered to the public.

What the app accesses

With the owner's permission, the app uses the YouTube Data API to upload videos to the owner's channel and to read that channel's name to confirm the right channel is connected. It does not access any other Google or YouTube data.

How data is stored and shared

The Google sign-in token is stored only on the owner's private server so uploads can run automatically. The app does not collect, sell or share personal data, and it does not use cookies or analytics.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data. Access can be revoked at any time from the Google security settings page.

Contact

Questions can be sent to the support email shown on the app's Google sign-in screen.
